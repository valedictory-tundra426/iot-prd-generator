iot-prd-generator helps you create structured PRD files for IoT software work. It brings together near-field Bluetooth and remote 4G data points, maps them to software functions, and turns page screens, `spec.md`, and feature scope into a clear document for development and testing.

Use it when you need one place to keep product needs aligned, check changes, and hand off work with less back and forth.

## 📌 Input Files and Expected Use

### 1. Page implementation
Use page details to show how the app works on screen. This helps turn visual flow into product language.

### 2. `spec.md`
Use this file as the main source for rules, limits, and behavior. The tool uses it to keep the PRD aligned with the product plan.

### 3. Feature scope
Use scope notes to define what is in and what is out. This helps prevent new work from slipping into the wrong release.

### 4. DP data points
Use Bluetooth near-field and 4G remote protocol points to connect device data with software actions. This is useful for device control, status sync, and event handling.
